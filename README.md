# 🥾 הטיולים שלנו — אפליקציה לניהול טיולים

אפליקציית ווב (בעברית) לשלושה חברים: טיולים, מסלולים, מפה (כולל קבצי GPX), תמונות, הוצאות (מי חייב למי), לו״ז והצבעה על תאריכים, וייבוא מצ׳אט הוואטסאפ.

כל הנתונים נשמרים ב־Google Drive שלך, בתיקייה `תכנות/טיולים` (כונן G: אצלך במחשב):

| מה | איפה |
|---|---|
| הנתונים (טיולים, מסלולים, הוצאות, הצבעות) | גיליון `הטיולים שלנו – נתונים` |
| תמונות | תיקייה `תמונות` (נוצרת לבד) |
| קבצי GPX | תיקייה `קבצי GPX` (נוצרת לבד) |

## התקנה (פעם אחת, כ־5 דקות)

1. פותחים את הגיליון **הטיולים שלנו – נתונים** בתיקייה `תכנות/טיולים`.
2. בתפריט: **תוספים (Extensions) ← Apps Script**.
3. בקובץ `Code.gs` מוחקים את מה שיש ומדביקים את התוכן של `Code.gs`.
4. לוחצים **+** ליד "קבצים" ← **HTML**, קוראים לו `Index` (בדיוק כך), ומדביקים את התוכן של `Index.html`.
5. שומרים (Ctrl+S). בוחרים בפונקציה `setup` למעלה ולוחצים **הפעלה (Run)**.
   מאשרים את ההרשאות. אם מופיע "Google hasn't verified this app": **Advanced ← Go to … (unsafe)**. זה הסקריפט שלך, אז זה בסדר.
   **ייבוא הנתונים משלוש קבוצות הוואטסאפ:** מוסיפים עוד קובץ סקריפט (**+ ← Script**) בשם `Seed`, מדביקים את `Seed.gs`, בוחרים בפונקציה `importWhatsAppData` ולוחצים **Run** פעם אחת.
   הפעולה מוסיפה 9 מסלולים, 6 טיולים, 2 הוצאות ותמונות וסרטונים מכל הטיולים (מהקבצים בדרייב – כדאי להריץ אחרי שהסנכרון של הדרייב הסתיים), כולל הטיול הראשון בגליל באפריל 2021, ומשנה את שמות החברים לבנג׳י, אביב ויוני. מה שכבר קיים לא נוסף שוב, אז אפשר להריץ שוב בלי חשש.
6. **פריסה (Deploy) ← פריסה חדשה (New deployment)** ← סוג: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone with Google account**
   - לוחצים Deploy ומעתיקים את הקישור (מסתיים ב־`/exec`).
7. שולחים את הקישור לחברים. בטלפון: תפריט הדפדפן ← "הוספה למסך הבית", וזה נראה כמו אפליקציה.
8. באפליקציה כל אחד בוחר את השם שלו למעלה. אפשר לשנות שמות דרך ⚙︎.

### עדכון קוד בעתיד
אחרי שמדביקים קוד חדש: **Deploy ← Manage deployments ← ✎ ← Version: New version ← Deploy**. הקישור לא משתנה.

## ייבוא מהוואטסאפ
1. בקבוצה: שם הקבוצה ← **ייצוא צ׳אט** ← **ללא מדיה**. מתקבל קובץ `.txt` (לפעמים בתוך ZIP; פותחים אותו).
2. באפליקציה: לשונית **ייבוא מוואטסאפ** ← בוחרים את הקובץ.
3. האפליקציה מסננת הודעות עם קישורי מפות/מסלולים וסכומים בשקלים. ליד כל הודעה יש **+ מסלול / + טיול / + הוצאה**, והטופס נפתח כבר ממולא.
   קישורי `maps.app.goo.gl` מתורגמים אוטומטית לנקודה על המפה.
4. תמונות: מייצאים **כולל מדיה**, פותחים את ה־ZIP, ומעלים בלשונית **תמונות** (אפשר לבחור הרבה בבת אחת; התמונות מוקטנות אוטומטית).

הקובץ נקרא רק בדפדפן. שום דבר לא נשמר עד שלוחצים "+".

## פרטיות
- כל מי שיש לו את הקישור וחשבון גוגל יכול להשתמש באפליקציה, אז שתפו אותו רק בקבוצה.
- תמונות שמועלות מקבלות הרשאת "כל מי שיש לו את הקישור – צפייה", כדי שיוצגו לכולם באפליקציה.

## קבצים
- `Code.gs`: צד השרת (Apps Script): קריאה וכתיבה לגיליון, העלאת תמונות ו־GPX.
- `Seed.gs`: ייבוא הנתונים מקבוצות הוואטסאפ (ייצוא מ־8.11.2026).
- `Index.html`: כל הממשק (RTL, מותאם לטלפון). מפות: Leaflet + OpenStreetMap / OpenTopoMap / מפת השבילים של Israel Hiking Map.
